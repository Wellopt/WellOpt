# WellOPT Nigeria Ltd Website

## Project Overview

WellOPT is Nigeria's leading indigenous provider of expert slickline, wellhead maintenance, and BHP data acquisition services. This website showcases our services and expertise in the oil and gas industry.

## Technologies Used

This project is built with:

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Development Setup

### Prerequisites
- Node.js & npm installed

### Installation Steps

1. Clone the repository
```sh
# Step 1: Clone the repository using the project's Git URL.
git clone <YOUR_GIT_URL>

# Step 2: Navigate to the project directory.
cd WellOpt

# Step 3: Install the necessary dependencies.
npm install

# Step 4: Start the development server with auto-reloading and an instant preview.
npm run dev
```

### Development Commands

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
- `npm run lint` - Run ESLint

## Deployment

The site can be deployed using any static site hosting service. Build the project and deploy the contents of the `dist` folder.

If you have a custom domain, you can configure it with your hosting provider's domain settings.
